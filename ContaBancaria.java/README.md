Este projeto simula as operações essenciais de um banco, utilizando o padrão de arquitetura **MVC (Model-View-Controller)** para garantir uma separação clara entre a lógica de negócio e a interface com o usuário.

## 🛠️ Tecnologias e Conceitos
- **Java 17+**
- **Arquitetura MVC:** Organização do código em camadas de Modelo, Visão e Controle.
- **Encapsulamento:** Proteção de dados sensíveis (como saldos) usando atributos privados e métodos acessores.
- **Java Collections (ArrayList):** Gerenciamento dinâmico de contas bancárias.

## 🚀 Funcionalidades
* **Listar Contas:** Exibe os dados de todas as contas cadastradas.
* **Depósito:** Adiciona fundos a uma conta via número identificador.
* **Saque:** Retira valores após validar a existência de saldo suficiente.
* **Transferência:** Realiza o envio de valores entre duas contas distintas com validação de integridade.

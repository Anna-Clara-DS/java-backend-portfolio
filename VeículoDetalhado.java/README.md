Uma aplicação que utiliza os pilares da Orientação a Objetos para modelar e gerenciar veículos, focando na especialização de dados técnicos e reaproveitamento de código.

## 🛠️ Tecnologias e Conceitos
- **Java 17+**
- **Herança:** Reutilização de código da classe base para especializações.
- **Polimorfismo:** Sobrescrita de métodos para comportamentos únicos (ex: cálculo de autonomia).
- **Encapsulamento:** Proteção de atributos sensíveis como chassi e motorização.

## 🚀 Funcionalidades
* **Cadastro Técnico:** Registro de placas, motorização e especificações de fábrica.
* **Cálculo de Autonomia:** Método para prever a distância percorrida com base no combustível.
* **Relatório de Detalhes:** Exibição formatada das propriedades técnicas de cada veículo.

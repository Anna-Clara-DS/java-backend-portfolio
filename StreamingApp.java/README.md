Este projeto simula o backend de uma plataforma de streaming, focado na organização, categorização e recuperação eficiente de conteúdos audiovisuais como filmes e séries.

## 🛠️ Tecnologias e Conceitos
- **Java 17+**
- **Lógica de Filtros:** Implementação de algoritmos para busca dinâmica por categoria ou título.
- **Manipulação de Listas (ArrayList):** Gerenciamento dinâmico do catálogo de mídia em memória.
- **Abstração de Dados:** Uso de classes para representar diferentes tipos de conteúdo.

## 🚀 Funcionalidades
* **Gerenciar Catálogo:** Adicionar, remover e listar títulos disponíveis na plataforma.
* **Busca Inteligente:** Localizar conteúdos específicos através de parâmetros de entrada.
* **Perfis de Usuário:** Estrutura base para separar preferências e históricos.
